# Team Crazy

The public team identity site for Team Crazy.

## Stack

- HTML
- CSS
- Vanilla JavaScript

No framework. No backend. No build step.

## Run

Open `index.html` directly or use any static server.

## Member photos

The site is already complete without photos: it falls back to initials.

For the final version, add these files:

- `assets/members/vaibhav.jpg`
- `assets/members/ayush.jpg`
- `assets/members/aditya.jpg`
- `assets/members/samarth.jpg`
- `assets/members/anushka.jpg`
- `assets/members/sakshi.jpg`

Recommended source photos: professional camera-facing portrait, preferably portrait orientation. The CSS crops them to **4:5** automatically.

## Logo

`assets/team-crazy-logo.jpg` is cropped from the supplied logo screenshot. For the cleanest final deployment, replace it with the original logo file if you have the source asset.

## Deployment

This is a static site and can be deployed to GitHub Pages, Netlify, Vercel static hosting, Cloudflare Pages, or any normal web server.
